# Dream Language Server

An LSP server for Dream, using the Tree-sitter WASM parser generated by this repository.

Current capabilities:

- Document synchronization and syntax diagnostics
- Document symbols
- Hover information
- Completion
- Go to definition
- Find references
- Rename
- Folding ranges

## Build

Run from the repository root:

```sh
cd lsp
bun install
bun run build
```

The build produces one self-contained executable at `lsp/dist/dream-language-server`.
It embeds the Bun runtime, dependencies, Tree-sitter runtime WASM, and Dream grammar WASM.

For a non-compiled JavaScript bundle during development, use `bun run build:js`.

## Run

The server communicates over stdio:

```sh
lsp/dist/dream-language-server
```

Set `DREAM_TREE_SITTER_WASM` to override the parser path. For development:

```sh
bun run dev
```

## Verify

```sh
bun run typecheck
bun test
```
